The dashboard reads .bestest/state/metrics.json which is generated by bestest commands.

Get started:

/bestest init then /bestest scan to populate initial metrics.
After that, run /bestest run to see live test results here.

Tip: Open this file via a local server if fetch fails from file://. Try: python3 -m http.server in the .bestest/ directory.
